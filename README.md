O QUE É SQL?
STRUCTURED QUERY LANGUAGE 
- usado para comunicação em banco de dados
- IBM foi a primeira a desenvolver um banco de dados SQL (EDGAR CODD, DECADA DE 60)
- É usado para acesso, manipulação e recuperação de dados

PARA COMUNICAÇÃO O SQL UTILIZA
- 4 sublinguagens:
- DQL (DATA QUERY LANGUAGE) ele é usado para CONSULTA de dados 
-      SEUS PRINCIPAIS COMANDO INCLUEM : SELECT

-  DDL (DATA DEFINITION LANGUAGE)
-  usado para cria e modificar tabelas, views, usuarios e outros objetos
-       HÁ 3 COMANDOS COMUNS : CREATE ALTER e DROP
-   CREATE: CRIAÇÃO DE NOVOS OBJETOS
-   ALTER: ALTERA ESTRUTURA DE UM OBJETO
-   DROP: EXCLUI O OBJETO INTEIRO E SUA ESTRUTURA
